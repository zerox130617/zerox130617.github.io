## 為什麼選擇 GitHub Pages？

我選擇使用 GitHub Pages 搭配 Jekyll，是因為它：

1.  **完全免費：** 零託管費用。
2.  **版本控制：** 所有的文章和程式碼都在 Git 版本控制下。
3.  **速度快：** 靜態網頁載入速度極佳。
